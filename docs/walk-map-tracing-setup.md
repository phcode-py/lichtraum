# Map tracing paper — setup for Philipp

The walk's “Tracing paper” row opens a geographic drawing layer. Participants can draw their own blue lines, place/edit short notes, upload up to three still-image sketches, align them by moving/resizing/rotating, replace a sketch image without losing its placement, change opacity, and hide/show the layer. The blue tape drags the controls paper (arrow keys work when it is focused). The selection arrow also lets you pan the map by dragging empty space. It moves existing lines and notes, exposes line handles for reshaping, and lets you remove a selected line. Notes can be rewritten or removed. Undo restores draft changes. Map coordinates keep the work aligned when panning and zooming. Unsaved work stays in memory while moving between walks in the same page; Save commits the personal layer. Browser reloads require saving first.
